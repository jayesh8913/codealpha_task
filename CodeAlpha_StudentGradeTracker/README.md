# Student Grade Tracker (Java)

A simple Java-based desktop application to manage student marks and calculate basic statistics like **average, highest, and lowest scores**.  
The project uses **Java Swing** to provide a clean and user-friendly graphical interface.

---

## ✨ Features
- Add student name and marks
- Display student data in a table
- Automatically calculates:
  - Average marks
  - Highest marks
  - Lowest marks
- Simple and clean GUI using Java Swing

---

## 🛠 Technologies Used
- Java
- Java Swing (GUI)
- JTable for data display
